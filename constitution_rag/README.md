## Оценка качества

Набор: `eval/questions.csv`, 39 позитивных и 9 негативных вопросов.
Позитивные сформулированы бытовым языком и юридическими терминами,
негативные включают «трудные» вопросы из соседних правовых областей
(исковая давность, испытательный срок, пособие по безработице).

Метрики ранжирования считаются без порога. «Зазор» — разница между худшим
скором позитивного вопроса и лучшим скором негативного: чем он больше, тем
надёжнее порог «не найдено». Refusal accuracy — при пороге, подобранном для
каждой конфигурации отдельно.

### Выводы

- Ранжирование на этом наборе почти насыщено: recall@5 = 100% у всех
  конфигураций без BM25, разница в recall@1 — 1–2 вопроса (в пределах шума).
  Различает конфигурации в первую очередь зазор.
- Префиксы e5 и заголовок в embed_text почти не влияют на ранжирование, но
  сильно влияют на зазор (0.001 и 0.004 без них против 0.020 с ними).
- BM25 ухудшает ранжирование: на перефразированных вопросах он находит
  случайные совпадения слов («без согласия» из ст. 24 вместо ст. 25 для вопроса
  про квартиру), а RRF награждает такие совпадения. Запросы по номеру статьи,
  ради которых BM25 был нужен, обрабатывает точная выборка. Выключен по умолчанию.
- e5-base не лучше e5-small по ранжированию, хуже по зазору, втрое медленнее
  при индексации.
- Итоговая конфигурация: e5-small, префиксы и заголовок, без BM25,
  чанки 200–900 символов со слиянием, min_score = 0.829.

### Ограничения

Набор маленький: один вопрос — 2.6 п.п. recall, зазор определяется двумя
крайними вопросами. На наборе из 37 вопросов e5-base давала лучший зазор,
а после добавления двух трудных негативов — худший. Для уверенных выводов
нужен набор больше и труднее.
