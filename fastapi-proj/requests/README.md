# Коллекция запросов

Файлы в формате `.http` — открываются в VS Code с расширением
[REST Client](https://marketplace.visualstudio.com/items?itemName=humao.REST-Client)
или в IDE JetBrains без дополнительных плагинов.

| Файл | Содержание |
|---|---|
| `00-scenario-full.http` | Сквозной сценарий от регистрации компании до срабатывания саги онбординга. Выполнять по порядку |
| `01-auth.http` | Регистрация, аутентификация, управление сотрудниками |
| `02-org.http` | Оргструктура и должности |
| `03-tasks.http` | Задачи, статусы, участники |

## Как пользоваться

1. Поднять систему: `docker compose up` из корня проекта
2. Открыть `00-scenario-full.http` и выполнять запросы сверху вниз
3. Токены инвайтов забирать из MailHog: http://localhost:8025

Переменные вида `{{adminToken}}` подставляются автоматически из ответов на
предыдущие запросы. Значения с плейсхолдерами `PASTE_...` нужно вписать вручную —
это либо токены из писем, либо идентификаторы, которые удобнее взять из Swagger
или напрямую из базы.

Запросы, помеченные комментарием «ожидается 4xx», проверяют обработку ошибок:
guard-переходы статусов, права доступа, изоляцию между компаниями.

## Альтернатива

У каждого сервиса есть автогенерируемая OpenAPI-документация с возможностью
выполнять запросы прямо из браузера:

- http://localhost:8000/docs
- http://localhost:8002/docs
- http://localhost:8003/docs
